WSA Multi-Channel Publisher - ZERO SETUP PORTABLE EDITION

HOW TO RUN ON XAMPP
1. Extract this folder into:
   C:\xampp\htdocs\WSA_Publisher
2. Start Apache from XAMPP.
3. Open:
   http://localhost/WSA_Publisher/

NO composer install.
NO php spark migrate.
NO php spark serve.
NO MySQL import.

The SQLite database is created automatically on first visit.

DEFAULT LOGIN
Email: admin@wsa.com
Password: admin123

SERVER
Upload the entire folder into your web root/public_html subfolder and open its URL.

REQUIREMENT
PHP 8.1+ with PDO SQLite enabled.
On most XAMPP installs SQLite is already available.

IMPORTANT
This portable edition provides dashboard/account/campaign/manual-queue/report workflow immediately.
Real publishing to Facebook, Instagram, Blogger, WordPress, etc. still requires each platform's official API/OAuth credentials and supported permissions.
Do not store social-network account passwords in this app.

For production, change the default admin password and use HTTPS.
